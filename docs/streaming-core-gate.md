# Core live streaming gate

Safe Gemini turns stream provider-approved text deltas through the core without requiring native web mode.

Buffered classes remain:
- enterprise-grounded turns,
- SAP diagnosis turns,
- requests containing exact custom identifiers such as `Z*` or `CHECK_*`,
- artifact and spreadsheet mutation turns.

This preserves post-generation grounding boundaries for high-risk technical claims while allowing generic Gemini answers to render incrementally.
